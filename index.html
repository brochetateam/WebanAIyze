Cómo funciona

Esto es 100% front-end. Tu API Key se usa solo en tu navegador. Sin backend, sin almacenamiento.

  • Le pasamos a Gemini prompts específicos para SEO, seguridad y un llm.txt.
  • Pedimos respuesta en JSON para poder dibujar puntuaciones y listas.
  • Si el modelo devuelve texto raro, hacemos fallback y te lo mostramos tal cual.
  • Descargas disponibles: informe TXT, datos JSON y copia rápida del llm.txt.

Nota técnica: sin servidor no podemos leer HTML real ni headers por CORS. Esto es una guía rápida/heurística. Para auditorías serias, meted un proxy simple y ya jugamos en otra liga.
